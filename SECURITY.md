# Security Policy

At CafeFlow, we take the security and integrity of our software and customer data seriously.

## Public Repository Notice

This repository contains **public documentation only**. It does not contain application source code, API keys, credentials, or private configuration files.

- **Never** post passwords, tokens, API keys, database connection strings, or customer private data in GitHub Issues, Pull Requests, or Discussions.
- If you notice any accidental disclosure of sensitive information in documentation examples, please notify us immediately.

## Reporting Security Vulnerabilities

If you believe you have found a security vulnerability in the CafeFlow platform or any associated service, please do **not** open a public issue.

Instead, please report security vulnerabilities responsibly through our official contact channels:

- **Official Website:** [https://www.cafeflow.fun](https://www.cafeflow.fun)
- **Support / Contact:** Use the official contact form or support channels available on [https://www.cafeflow.fun](https://www.cafeflow.fun)

### When Reporting, Please Include:

1. A clear description of the vulnerability and its potential impact.
2. Step-by-step reproduction instructions or a minimal proof of concept (without exploiting live data).
3. The affected environment, URL, or endpoint.
4. Your contact details so we can coordinate with you during remediation.

We appreciate the efforts of security researchers in keeping CafeFlow safe and reliable for cafes and restaurants worldwide.
