## Core Capabilities Matrix

| Capability | Status | Description |
| :--- | :--- | :--- |
| **QR Ordering** | Supported | Customers scan tabletop QR code to view live digital menu and submit orders via mobile browser. |
| **Digital Menu** | Supported | Cloud-managed menu catalog with item categories, descriptions, images, prices, and instant availability toggles. |
| **POS (Point of Sale)** | Supported | Web-based cashier terminal for counter orders, table tab tracking, and bill settlement. |
| **Staff Ordering** | Supported | Dedicated mobile interface for waitstaff to input orders directly at dining tables. |
| **Kitchen Display System (KDS)**| Supported | Real-time digital kitchen screen tracking 6 order states: *Received → Confirm → Preparing → Ready → Delivered → Paid*. |
| **Table Management** | Supported | Visual table layout management, occupancy tracking (*Vacant*, *Occupied*, *Billed*), and table QR generation. |
| **Customer Loyalty** | Supported | Phone-number-based customer visit and point accumulation system. |
| **Coupons & Discounts** | Supported | Configurable discount campaigns (percentage/flat), minimum order requirements, and coupon codes. |
| **Scratch Cards** | Supported | Post-transaction interactive digital scratch cards delivering return-visit reward vouchers. |
| **Google Review Workflow** | Supported | Automated satisfaction rating system routing positive customer reviews to Google Business profiles. |
| **TV Menu Display** | Supported | Full-screen dynamic web layout for wall-mounted smart TVs and counter menu displays. |

## Pricing Model Facts

- **Software Platform Monthly Fee:** ₹0 / month.
- **Fixed Subscriptions:** None.
- **Transaction Model:** Nominal per-eligible-order fee applied on successfully completed and settled orders.
- **Billing Configurations:** Supports store-based fee absorption or customer convenience fee structures where applicable.
- **Country Variations:** Country-specific fee structures and local currencies apply depending on the venue's operating region.

---

## Architecture & Deployment Facts

- **Deployment Model:** Web-based cloud platform.
- **Hardware Agnostic:** Does not mandate proprietary POS hardware or dedicated receipt printers.
- **Real-Time Data Sync:** Order updates, status transitions, and inventory availability propagate across POS, KDS, QR, and TV screens in real time.
