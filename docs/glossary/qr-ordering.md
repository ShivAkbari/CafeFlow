# Glossary: QR Ordering

## Definition

**QR Ordering** (Quick Response Ordering) is a contactless digital ordering method where customers scan a two-dimensional barcode (QR code) using a smartphone camera to view a venue's digital menu and submit food or beverage orders directly through a mobile web browser.

---

## How it Operates

1. **Table-Specific QR Codes:** The code contains an embedded identifier corresponding to a physical table or seat.
2. **Web Browser Execution:** Tapping the scanned link opens the ordering platform without requiring a native mobile app download.
3. **Automated Dispatch:** When submitted, the order routes automatically into the venue's Point of Sale (POS) and Kitchen Display System (KDS).

---

## Key Industry Benefits

- Decreases customer wait times during peak service hours.
- Reduces waitstaff order-taking travel time.
- Enables rich visual item presentation with photos, descriptions, and modifier selections.
