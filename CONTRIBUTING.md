# Contributing to CafeFlow Documentation

Thank you for your interest in improving the CafeFlow public knowledge base!

## Scope of this Repository

This repository is dedicated solely to **public documentation, guides, and informational materials** for CafeFlow. 

- This repository **does not** contain or host CafeFlow application source code.
- Pull requests attempting to submit application code or features cannot be accepted here.

## How You Can Contribute

We welcome community contributions that improve the accuracy, clarity, and completeness of our documentation:

1. **Typo and Grammar Fixes:** Correct spelling mistakes, grammatical errors, or awkward phrasing.
2. **Clarity and Readability Improvements:** Suggest clearer explanations of cafe operational workflows and features.
3. **Broken Links & Markdown Formatting:** Fix broken markdown links or formatting inconsistencies.
4. **Clarification Requests:** Open an issue if any section in the documentation is ambiguous or requires more detail.

## Contribution Guidelines

- **Maintain Factual Integrity:** All documentation must accurately reflect verified CafeFlow features and capabilities. Avoid speculative claims or unofficial benchmarks.
- **Tone and Style:** Keep explanations professional, concise, neutral, and easy to understand for cafe managers, restaurant owners, and developers.
- **No Secrets or Private Data:** Never commit secrets, mock customer credentials, internal API keys, or proprietary internal architecture details.
- **One Change per PR:** Keep pull requests focused on a single topic, guide, or set of related documentation files.

## Submitting a Pull Request

1. Fork the repository.
2. Create a feature branch (e.g., `fix/qr-ordering-typo` or `docs/update-pos-guide`).
3. Make your documentation edits.
4. Ensure your Markdown formatting is clean and all internal links are valid.
5. Submit a pull request with a descriptive summary of your changes.

For questions or broader feature inquiries, visit [https://www.cafeflow.fun](https://www.cafeflow.fun).
